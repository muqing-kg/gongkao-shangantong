> 2026-10-02 · 本文件是后续所有页面的准绳。改设计先改这里。

## 1. 品牌

| | |
|---|---|
| 名字 | **同舟共济**（窄处用「同舟」） |
| 副题 | 一起渡过这段路 |
| 一句话定位 | 一个人陪另一个人备考的地方 |
| 语气 | **安静的陪伴感**。不喊口号、不卖萌、不煽情 |

**为什么不做成粉红少女风**：她要拿这个刷题，一刷两小时。页面太"甜"会腻、会分散注意力。
可爱体现在**圆润的形状、柔和的颜色、温和的文案**上，不体现在装饰上。

## 3. 字体

### 3.1 字体栈

中文 Web 字体动辄数 MB，且国内访问 Google Fonts 不通，**不引外部字体**。用系统栈分级：

```css
--font-sans: "PingFang SC","HarmonyOS Sans SC","MiSans","Microsoft YaHei",system-ui,sans-serif;
--font-num:  ui-monospace,"SF Mono","JetBrains Mono",monospace;
```

**数字一律用等宽 + `tabular-nums`**：正确率、用时、题量这些数字跳动时不会左右抖。

### 3.2 字号阶梯（1.25 倍）

| 变量 | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 11px | 标签、脚注 |
| `--fs-sm` | 13px | 次要说明 |
| `--fs-base` | 15px | 正文 |
| `--fs-lg` | 17px | 卡片标题 |
| `--fs-xl` | 21px | 页面标题 |
| `--fs-2xl` | 28px | 大标题 |
| `--fs-3xl` | 34px | 数字展示 |

行高：正文 **1.7**，标题 **1.3**。大标题字距 `-0.02em`，小标签字距 `+0.06em`。

---

## 4. 间距

4px 基准：

```
--sp-1 4   --sp-2 8   --sp-3 12  --sp-4 16
--sp-5 20  --sp-6 24  --sp-8 32  --sp-10 40
```

- 卡片内边距 **18px**
- 卡片之间 **14px**
- 页面左右内边距：PC 32px / 手机 16px
- 段落之间 **12px**

## 5. 圆角与阴影

### 5.1 圆角（越大越"柔"，但不要全一样）

| 变量 | 值 | 用途 |
|---|---|---|
| `--r-sm` | 10px | 标签、小按钮 |
| `--r` | 16px | 按钮、输入框 |
| `--r-lg` | 20px | 卡片 |
| `--r-full` | 999px | 胶囊 |

### 5.2 阴影（**带主色色调，不用纯黑**）

```css
--shadow-sm: 0 2px 8px rgba(168,117,127,.06);
--shadow:    0 6px 20px rgba(168,117,127,.08);
--shadow-lg: 0 14px 40px rgba(168,117,127,.12);
```

光源统一**自上而下**。

## 6. 组件规格

### 6.1 按钮（三级）

| 级别 | 样式 | 用途 |
|---|---|---|
| primary | 主色渐变实底 + 白字 | 一屏最多一个 |
| ghost | 主色极浅底 + 主色字 | 次要操作 |
| text | 纯文字 + 主色 | 第三级，减少视觉噪音 |

- 高度：主要 **46px** / 小 **36px**（手机上触摸热区 ≥44px）
- 圆角 14px，按下 `scale(.97)`，过渡 150ms
- 必须有 hover 与 focus-visible

### 6.2 卡片

**无边框**，靠阴影与底色区分层级。内边距 18px，圆角 20px。
卡片标题：图标 + 15px 半粗 + 与正文间距 12px。

### 6.3 输入框

高度 46px，圆角 16px，1.5px 边（`--line-strong`），聚焦时边变主色。

### 6.4 空状态

**插画 + 一句温和的话 + 一个明确按钮**。三样缺一不可。
禁止只写「暂无数据」。

### 6.5 状态

| 状态 | 做法 |
|---|---|
| 加载 | 骨架屏（形状与真实内容一致），不用转圈 |
| 空 | 插画 + 温和文案 + 按钮 |
| 错误 | 行内提示 + 重试按钮，**不用 alert** |
| 完成 | 明确的收束语，不弹窗 |

---

## 7. 图标

- 自绘 SVG，24 视框，**1.8 描边**，圆头圆角
- 尺寸：`1.15em`（默认，跟随字号）/ `.lg` 1.5em / `.xl` 1.9em
- 颜色：`currentColor`（自动跟随文字色）
- **禁止 emoji**：字形随系统变、不能换色、深浅背景下不可控
- 存放：`js/icons.js`，用法 `${ico('book')}`

## 9. 文案规范

### 9.1 语气

像一个懂她的人在旁边。**鼓励要具体**。

### 9.2 红线

| 禁止 | 原因 |
|---|---|
| 感叹号堆砌 | 吵 |
| 「加油哦」「你真棒」 | 空洞，等于没说 |
| 口号式（「开启你的备考之旅」） | 假 |
| 「赋能」「抓手」「闭环」 | 官腔 |
| 页面出现称呼（「老婆」等） | 她给别人看手机时会尴尬 |

### 9.3 核心原则：**数据标签保持准确，陪伴感放在对话性文案上**

「累计做题」「正确率」这类**数据标签不要动**——她要的是看清数据。
温暖放在**问候、空状态、结果、鼓励**这些"人对人说话"的地方。

### 9.4 对照表

| 位置 | 现在 | 改成 |
|---|---|---|
| 首页大标题 | 同舟共济 · 今日备考 | **今天也一起** |
| 首页副行 | 今日还没开始，刷几题保持手感吧！ | **还没开始呢，不着急** |
| 连续打卡标签 | 连续打卡(天) | 坚持了 |
| 待复习标签 | 今日待复习 | 今天要复习 |
| 空状态 | 还没有作答记录——先刷几题 | **今天还没动笔** + 插画 + 「开始今天的 20 题」 |
| 交卷结果 | 🎉 判卷完成：12/20 正确（60%） | **这一轮 12/20** · 错的都记下了 |
| 错题本空 | 暂无错题 | **一道错题都没有，今天很稳** |
| 题库加载 | 正在加载完整题库… | **题库在准备了，稍等一下** |
| 加载失败 | 完整题库加载失败，请检查网络后重试 | **题库没加载上**，检查下网络？ + 重试 |
| 该备份了 | 该备份了 | **记录该存一份了** |
| 关于 | （技术说明） | 为你而做 |
| 备考小贴士 | （写死的通用建议） | **删除**（AI 诊断已能按她的真实数据给具体建议） |

### 9.5 AI 的人格

```
你是一位耐心的公考辅导老师，正在帮一位备考省考的考生。
这套系统是她的伴侣为她搭的——你的回答应当温和、笃定，
像一个认识她、希望她好的人在旁边陪着。

但要注意分寸：
- 温和不等于空泛鼓励。该指出的问题要直接指出，她要的是提分，不是安慰。
- 不卖萌、不堆感叹号、不说「加油哦」这类空洞的话。
- 鼓励和批评都要具体到她的数据和题目，不要泛泛而谈。
- 用中文，说人话。
```

## 10. 响应式

| 端 | 宽度 | 布局 |
|---|---|---|
| PC | ≥1200px | 左导航 220px + 内容区（最大 880px）+ 右侧信息栏 |
| 平板横屏 | 768–1199px | 左图标栏 76px + 单栏 |
| 平板竖屏 | 640–767px | 顶部导航 + 单栏，卡片两列 |
| 手机 | <640px | 底部 tab（≤5 项）+ 单栏，按钮 ≥44px |

**要点**
- 答题层在手机上必须**真正全屏**（现在题干长了会挤）
- 题库图片支持**双指缩放**（资料分析图表要看清）
- 打印样式保留（她要打印卷子）
- 全屏区块用 `min-height:100dvh`，不用 `100vh`

## 11. 导航（6 项 → 5 项）

```
首页 · 行测 · 申论 · 成长 · 我的
```

**改动理由**
- 「错题本」从「行测」里**提到一级**——她备考后期主要刷错题，现在藏两层太深
- 「问泽」**降为全局悬浮入口**（顶栏 + 题目下方），不再占 tab
- 「更多」页拆解：打卡日历→首页、复习提醒→错题本、缓存与数据→「我的」
