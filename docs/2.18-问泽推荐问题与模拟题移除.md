# 上岸通 2.18 · 问泽推荐问题修复与模拟题移除

> 日期：2026-10-02 · 范围：两个用户报的问题，外加一次题库瘦身

## 1. 「为什么不能选 B」是写死的

用户报：题目上一直显示「为什么不能选 B」，但她选的不是 B。

根因在 `ASK_PROMPTS`：

```js
// 改前
const ASK_PROMPTS={home:['今天先练什么','为什么不能选 B','帮我安排 30 分钟复习'],
                   ai:[...], question:['为什么不能选 B','换个角度讲','总结这个考点']};
```

`question` 那一组是**硬编码的固定文案**，与实际作答毫无关系。

改为按实际作答生成（`askPromptsFor()`）：

| 情况 | 第一个推荐问题 |
|---|---|
| 答错，选了 A | 为什么不能选 A |
| 答错，选了 C | 为什么不能选 C |
| 答对，选了 B | 我选的 B 是怎么对的 |
| 多选只选了 A | 为什么不能选 A |
| 未作答 | 这道题考的是什么 |

后两个（换个角度讲 / 总结这个考点）保留。

首页与问泽页的推荐问题也一并扩了，并把那条串到题目上的话去掉：

```
首页：今天先练什么 · 帮我安排 30 分钟复习 · 我哪个模块最该补 · 数量关系总做不完怎么办
问泽：分析我的薄弱项 · 制定今日学习计划 · 如何提高做题速度 · 我的错因主要是什么
```

## 2. 首页/问泽页的提问现在带上学情数据

上面这些推荐问题（「今天先练什么」「我哪个模块最该补」）**不带数据问等于白问**。
所以 `sendAsk` 在非逐题上下文里改为发送 `学情快照 + 问题`（`askStudyPrompt()`）。

- 数据少于 20 题时不带，免得 AI 拿零星数据瞎判断；
- 只发统计量（模块正确率、用时、错因、考点名），**不含题干与答案**；
- 「我的书斋 → 隐私与关于」与提问框提示同步更新为「会发送学情统计」。

## 3. 问泽框取不到题目的 bug

用户报：打开题目问 AI，一直说没获取到题目。

根因：问泽框在**两处**出现——答题页答完题之后、以及逐题回顾页。
而 `askQuestionCtx()` 里写了 `Q.mode==='review'` 这个条件：

```js
// 改前
function askQuestionCtx(){
  if(Q.mode==='review' && ...) return {...};
  return null;
}
```

答题页的 `Q.mode` 是 `multi`/`single`，不是 `review`，所以答完题提问永远取不到题。
当时是**假设问泽框只在回顾页出现**，假设错了，守卫就写错了。去掉该条件即可。

测试补了一条：答题页答完题后提问，请求里必须带题干与题库解析。

44,312 与「按来源考试统计的模考数」完全吻合。于是**整批删除这 52 个文件（131.7 MB）**。
