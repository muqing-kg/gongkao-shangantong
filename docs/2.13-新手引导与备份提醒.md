# 上岸通 2.13 · 新手引导与备份提醒

> 日期：2026-10-02 · 范围：补上「拿起来就能用」与「数据别丢」两件事

## 1. 为什么这两件事算「成品」的一部分

**新手引导。** 之前第一次打开只有一句「今日还没开始，刷几题保持手感吧」，她不会知道
还有学习计划、错因标注、申论练笔这些功能。功能齐了但找不到入口，等于没有。

**备份提醒。** 架构上选了「内容集中、数据本地」——服务器不存任何用户数据。
这条取舍的已知短板就是：**换手机、清浏览器数据，全部学习记录就没了**。
既然是主动做的取舍，就必须在界面上主动兜底，不能等出事。

## 2. 新手引导

首页在 `store.stats.answered === 0` 时显示一张「第一次来？三步开始」卡：

1. 到「修业成长 → 学习计划」填考试日期和每天想练多少题
2. 点「每日一练」，先把今天的量做掉
3. 做错的题会自动进错题本；在逐题回顾里标一下错因，App 才看得出失分在哪

两个按钮直接跳「学习计划」和「申论」。

## 3. 备份提醒

`store.settings.lastExport` 记录上次导出备份的时间戳（随备份文件往返）。

`backupStatus()` 的判定：

| 状态 | 结果 |
|---|---|
| 没有任何学习数据 | 不提醒，说明「暂时不用备份」 |
| 有数据但从未导出 | **告警**：「换手机或清浏览器数据就会全部丢失，建议现在导出一份」 |
| 距上次导出 ≥ 14 天 | **告警**：显示具体天数 |
| 距上次导出 < 14 天 | 不告警，显示「今天／N 天前」 |

告警出现在两处：首页一张红边卡片（带「立即导出备份」按钮）、
「我的书斋 → 数据管理」的说明文字。

导出后立刻 `renderView(currentView())` 重绘——否则首页那张告警卡要等下次切换页面才消失
（这是本次测试抓到的一个真实 UX bug）。

## 4. 验收

```
SAT_TEST_URL=http://127.0.0.1:8140/index.html python scripts/test_v213_guide.py
==== v2.13 首次引导与备份提醒验收：通过 23/23，失败 无 ====
```

覆盖：零数据时显示引导且不告警、有数据未备份时告警并说明后果、
数据管理卡同步显示、导出后记录时间且提醒立即消失、13/14/40 天三档阈值、
备份时间随备份文件往返、非法值归零、旧备份缺字段补 0。

## 5. 本次未做

1. **备份文件命名带版本**——目前是 `致泽学堂备份_YYYY-MM-DD.json`，同一天多次导出会重名。

3. **跨设备同步**——那需要后端，与当前「数据本地」的取舍冲突，需要主人另行决定。
